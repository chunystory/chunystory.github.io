    どう測るのか

    体温ではなく、言葉の結に付けた温度

    六つの話し方に、冷たい側からあたたかい側へ温度をひとつずつ付けました。36.5℃、あっさりが原点です。左へ行くと言葉は冷え、右へ行くとあたたまります。文を選ぶときに決める温度と、声から測った温度は、同じ六つの目盛り、同じ物差しなので、二つをそのまま見比べられます。

    1. 35.0℃きっぱり揺れない、はっきりした言葉
    2. 35.7℃おだやか低く、そろって落ち着いた声
    3. 36.5℃あっさり原点飾りのない淡々とした言葉
    4. 37.1℃たのしく軽く速いリズム
    5. 37.7℃共感相手の様子を先に見る言葉
    6. 38.2℃あたたかく気持ちがにじむぬくもり

    アプリの中で温度は色ひとつでは伝えません。色と数字と名前と線の形、四つが一緒に語ります。

    音から温度までの6つのステップ — くわしく見る

    音から温度まで、六つの歩み

    測っている間、画面の針は直近 4.5 秒を見て、部屋の暗騒音より上に出た音で動きます。終えると一回分をもう一度測り直し、その値が残ります。残るのは一回ごとに温度ひとつと時刻だけです。

    1. 聞きます

      70ms ごとに一コマを読みます。コマごとに音量（dBFS）、自己相関で見つけた音の高さ（Hz）、声の帯域（300〜3400Hz）の割合、そしてコマの中の 10ms ごとの音量七つが一緒に来ます。

      70ms ごと · 音量 dBFS · 音の高さ Hz · 10ms の音量 × 7

    2. 部屋を引き、話し声を見分けます

      部屋の暗騒音を録音の間ずっと追いかけ、その上に出た音を測ります。声の帯域と、毎秒 3〜5 回うねる音節のリズムが一緒にある箇所を話し声として見分け、音の高さはそこでだけ読みます。残ったコマからは、部屋が上乗せした分を引きます。

      x′ = 10·log10( 10x/10 − 10floor/10 ) — 12dB を超えては削らない

    3. 五つを人の物差しで測ります

      点数にする前に、人が使う単位でまず測ります。抑揚の幅は自分の真ん中の高さから散らばった半音なので、声の高い人も低い人も同じ物差しです。速さは 10ms の音量で谷に区切られた山（音節の母音）の数を音の出ていた時間で割った値、間の割合は話し始めから話し終わりまでの音のない割合、大きさは部屋を引いた平均、そろった音量はそのばらつきです。

      抑揚の幅 = σ( 12·log2( f / f̃ ) ) — 半音、f̃ は自分の真ん中 速さ = 山の数 ÷ 音の出ていた時間 — 音節/秒 間の割合 = 静かなコマ ÷ 最初の言葉から最後まで 大きさ = μ(dBFS) · ばらつき = σ(dB) — 部屋を引いた値

    4. ふつうの人の朗読に置きます

      五つの値をすべて同じ規則で 0〜100 に置きます。50 は韓国語の朗読 226 件（FLEURS）の中央値、四分位範囲ひとつが 25 点です。そのため、ふつうの朗読の真ん中の半分が 37.5〜62.5 に入り、六つの話し方の基準も人が実際に出せる範囲の中に立ちます。抑揚の「ふつう」だけは、話し方タブの声の基準（標準・男性・女性）に合わせます。

      点数 = 50 + 25 × ( 値 − 中央値 ) ÷ 四分位範囲

    5. 温度にまとめます

      言葉の温度は、五つの点数を重みどおりに足した値です。抑揚がほとんどを決め、大きさは少し冷まし（大きくはっきりするほど「きっぱり」側）、間は少し温めます。速さとそろった音量は温度を動かさず、六つの話し方のどれに近いか — 結の形 — だけを分けます。足し算なので、どの物差しも向きはひとつで、結果はいつも 34.7℃〜38.5℃ の中に立ちます。

      言葉の温度(℃) = 36.5 + 1.0·(抑揚 − 50)/25 − 0.25·(張り − 50)/25 + 0.1·(間 − 50)/25 速さ × 0 · そろった音量 × 0 — 結の形（一致度）にだけ使います

    6. 目標と比べ、ひとつだけ勧めます

      目標から 0.45℃ 以内なら、目標どおりに話したと見ます。同じ人が同じ結で読んでも文ごとに抑揚が違い、15 秒の一回の揺れが標準偏差でおよそ 0.44℃ だからです — 一回の値で隣の話し方まで分けはしません。外れたときは、温度を動かす物差しのうち「重み × 目標までの残り点数」がいちばん大きいものをひとつ勧めます。重みの向きは物差しごとにひとつなので、勧めどおりに話せば温度は必ず目標に近づきます。

      目標どおり = | 温度 − 目標 | ≤ 0.45℃ · 勧める物差し = いちばん大きい ( 重み × 残り点数 )

    FLEURS の韓国語朗読 226 件（CC-BY-4.0）を発話ごとに平均 −42dBFS にそろえてから、アプリと同じコードで測った値です。大きさの 50 点は音声コーパスでは決められないため、静かな部屋でスマホを手に持って話したときの真ん中（−42dBFS）を置き、25 点を 6dB — スマホと口の距離が二倍になった分 — としました。速さは、パッチムのない音節が続くと二つが一つに数えられるため実際の音節の 0.8 倍ほどになりますが、目盛りも同じ数え方で測ったので、その分は打ち消されます。

    なぜ声から温度が出るのか

    体温を測るのではありません
    言葉の温度は、言葉の結に付けた比喩です。物理的に測るのは抑揚の幅、話す速さ、間の割合、音の大きさとそのばらつきの五つで、どれもマイクが端末の中で確実に測れる量です。
    温度になる場所は宣言です
    六つの話し方に温度をひとつずつ付け、自分の声を同じ式に通して一本の線の上の数字に移します。六つの話し方の基準をその式に入れるとそれぞれの温度になるように置いたので、文を選ぶときの温度と声から測った温度を同じ物差しの上で見比べられます。
    部屋にも声の高さにも左右されません
    暗騒音を引くので、カフェと寝室が同じ物差しの上に立ちます。抑揚は絶対的なピッチではなく自分の真ん中からの半音で測ります。それでも同じ朗読で女性話者のほうが抑揚を広く使ったため（中央値 2.56 対 3.12 半音）、話し方タブで声の基準を選ぶと抑揚の「ふつう」をそちらに合わせます。最初は男女のちょうど真ん中です。スマホを二倍近づけても、温度は 0.25℃ ほどしか動きません。
    目盛りは人の声で合わせました
    五つの物差しの 50 点は韓国語の朗読 226 件の中央値で、あっさりはその場所そのままです。速さの数え方も、台本の実際の音節数を正解にして選びました。ほかの五つの話し方をどれだけ動かすかはまだ判断なので、話し方ごとに読んだ録音が集まるたびに直していきます。
    しないこと

    このアプリの性格は、しないと決めたことが決めます

    • 診断しません。音量から読んだ値を、感情、人格、心の健康、関係の質を判定する情報には使いません。医療や相談の代わりにはなりません。
    • 成績表をつくりません。グラフの基準線は 36.5℃ ではなく自分の平均です。比べる相手が自分だけなので、等級は生まれません。点数も連続記録もありません。まだ話していない相手は 0 ではなく「まだ」です — 0℃ では、とても冷たく話したことになってしまうからです。
    • 相手を操る文はつくりません。相手に勝つ文、説得する文ではなく、自分の気持ちと自分の境界を一緒に伝える文をつくります。
    • 危険の前では引きます。自傷、暴力、脅しの兆しが読まれたら、提案より先に案内と相談窓口の電話番号が立ち、その画面では広告も閉じます。
    • 書いたものをため込みません。アカウントはなく、書いた文も受け取った文もサーバーに残りません。「手放す」に書く文は一時保存もなく、端末のファイルにも一度も書き込まず、残るのは手放した日付と回数だけです。「すべて消す」一回で、端末の記録と匿名 ID が一緒に消えます。
    よくある質問

    謝るメッセージから声のトーンまで、気になること

    シール手帳を飾るのは無料ですか？

    はい。引き出しのシールと、ほとんどの効果 · 用紙 · 形は最初からひらいています。手の込んだ一部 — 効果16種、ブラック · ホワイトの用紙、矢印と名札の形いくつか — だけが広告を一本最後まで見るとひらき、一度ひらけばどのシールにもずっと使えます。アプリ内課金はありません。

    写真を貼ると、どこに保存されますか？

    選んだ写真のコピー一枚が、アプリ内のフォルダにだけ保存されます。当方のサーバーには送られず、写真を選ぶときもアルバムへのアクセスを求めません。書き出しファイルには写真が入らないため、新しいスマホでは貼った位置だけが残ります（iPhone で iCloud のデバイスバックアップをオンにしている場合は、そのバックアップにコピーが一緒に入ることがあります）。

    過ぎた日やこれから来る日も飾れますか？

    はい。ホームのカレンダーのどのマスを押しても、その日の一日のページが開き、その日に残した記録がシールになって先に座っています。過ぎた日もこれから来る日も飾れて、月のページではマスの境目なしにひと月をまるごと飾れます。紙が足りなければ下に一枚、横に一面ずつ広げられます。

    Malondo（マロンド）はどんなアプリですか？

    言いにくい場面で何を言うかを一緒に選び、その日の言葉と気持ちをシール手帳に残すアプリです。謝る · 断る · 頼む · 励ますのように最初の一文が出てこないとき、かける一言を4通り提案し、20秒ほど声に出して話すと、声から話し方の温度を測ります。その日にしたことはひとりでにシールになってホームの手帳に貼られ、その上を思いきり飾れます。アカウントなしで無料で使えます。

    「言葉の温度」とはどういう意味ですか？

    同じ言葉でも、どんな調子で言うかで冷たくも温かくも聞こえます。Malondo はその調子に温度をつけました。きっぱり 35.0℃ · おだやか 35.7℃ · あっさり 36.5℃ · たのしく 37.1℃ · 共感 37.7℃ · あたたかく 38.2℃。六つの話し方が一本の線の上に並び、文を選ぶときに決める温度と声で測った温度を同じものさしで比べます。体温を測るのではなく、言葉の調子にたとえた温度です。

    謝るメッセージや断りの連絡を、どう書けばいいかわかりません。

    「かける言葉を探したい」で、だれに（配偶者 · 恋人 · 家族 · 友だち · 同僚 · 上司）、何を（謝る · 断る · お願いする · なぐさめる · 対立をほどく · 気持ちを伝える · 意見を言う）、どんな調子で言うかを選び、あったことを一、二行書くと、行き方の違う文が四枚届きます。一枚ごとに、なぜこう言うのか、相手が答えてきたときに続ける一言、気をつける点が付きます。すでに書いた文は「自分の文を整える」で、意味はそのまま表現だけ直してもらえます。

    けんかのあと自分から連絡するときや、なぐさめの一言にも使えますか？

    はい。対立をほどく、なぐさめる、気持ちを伝えるがそのための入り口です。相手に勝ったり説き伏せたりする文ではなく、自分の気持ちと自分の境界を一緒に伝える文をつくり、「会話の練習」で、かけたあとのやりとりを先に一度歩いてみます。アプリが代わりに送ることはありません。選んで、自分の言葉に整えて、コピーして自分で送ります。

    自分の話し方や声のトーンが冷たく聞こえていないか、わかりますか？

    「言葉の温度を測る」で20秒ほど声に出して話すと、抑揚と速さ、間と声の大きさを端末の中で読み取って言葉の温度を測ります。選んだ目標の温度にどれだけ近いかが話している間リアルタイムで見え、終わると五つの軸の指紋の上に自分の声と目標を重ねて、どこが離れているかを見せます。点数ではなく次に試すことをひとつ書くので、提案された文を声に出して読み、話し方をやわらげてみる練習にも使えます。

    だれにも言えなかった話を打ち明ける場所がほしいです。

    「まず気持ちをほどく」にあったことを書いて、どんな答えが欲しいかだけ選ぶと（ただ聞いてほしい · 整理してほしい · 別の見方がほしい · どうすればいいか知りたい · 自分の分はどこまでか）、手紙が一通届きます。書いた話も返事も残りません。返事がいらない日は「手放す」に長く残っていたことをひとつ百字以内で書いて手で消し、その日の気持ちは「きょうの一マス」でカレンダーに残します。

    言葉を選ばない日にも使えますか?「窓辺の机」とは何ですか?

    はい。会話タブの五つめの扉「窓辺の机」に、とどまってつくる七つの場所があります。いい文を手で書き写すなぞり書き、送らない言葉を封じて決めた日に開く手紙、聞いたあたたかい言葉を紙の星に折って集める瓶、測るたびに咲くことばの花、一週間の温度で歌うオルゴール、夜に息で吹き消すろうそく。回数も広告もなく、つくったものはこの端末にだけ残ります。

    録音した声や書いた文は、どこに残りますか？

    声は端末の外に出ません。分析はすべて端末の中で行い、結果画面を離れると録音ファイルはすぐに消えます。会員登録はなく、書いた状況も受け取った文もサーバーに残りません。文や手紙をつくる瞬間にだけ、書いた状況と選んだ関係・目的・温度が Google Gemini に送られます。外に出るものの一覧はプライバシーポリシーにすべて書いてあります。

    シールが動くとバッテリーが心配です。

    効果は画面に見えているあいだだけ動き、動く効果のないページは時計を止めます。ドロワーの「画面と音」でシールの効果をまるごとオフにでき（選んだ効果は残り、オンにすると戻ります）、端末の「視差効果を減らす」をオンにすると止まった姿で表示されます。

    機種を変えたら記録を移せますか?

    はい。ドロワー → データとプライバシー → 移す の「書き出し」でファイルを一枚作り、新しいスマホで「復元」します。保存した文と測った記録、きょうの一マス、相手ごとの記録、窓辺の机でつくったもの、飾った一日のページと月のページ（写真は除いて貼った位置だけ）、話し方の学習と設定まで入り、復元は上書きせずに合わせます。ファイルはご自身で移し、当方は受け取りません。

    無料ですか？ 広告はありますか？

    無料で、アプリ内課金はありません。かける言葉は一日3回、手紙は一日2通まで受け取れ、使い切った日だけ、希望すればリワード広告を一本見て補充できます。シールの効果 · 用紙 · 形のうち手の込んだ一部も、広告一本でひらきます。「手放す」と「きょうの一マス」には回数制限も広告もありません。

    カウンセリングの代わりになりますか？

    なりません。Malondo は医療や心理カウンセリングのサービスではなく、感情や人格、関係を診断しません。自傷や暴力が心配される内容が読まれたら、文を提案する代わりに相談窓口の案内を先に出します。

    Android でも使えますか？ どの言語に対応していますか？

    iPhone は App Store、Android は Google Play から無料で入手できます。画面と提案される文は 한국어 · English · 日本語 · Español の四つの言語で届き、温度は ℃ と °F から選べます。
